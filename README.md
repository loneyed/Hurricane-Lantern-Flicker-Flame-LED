# Hurricane-Lantern-Flicker-Flame-LED
A PCB designed to retrofit a hurricane lantern. Based on the GE flicker flame LED light bulb.

Design Requirements:
1. Custom schematic and PCB design for the LED module.
2. Use parts from GE flicker flame light bulb to build PCB.
3. Hurricane lantern shouldn't be cut or damaged. The PCB module should fit into the existing body of the lantern without any harmful modificaiton.
4. The PCB module should be battery powered and should be rechargable.
5. A rotary switch to toggle battery power should replace the wick feeding knob on the lantern.
6. Battery capacity should allow LED to operate for 8+ hours.
